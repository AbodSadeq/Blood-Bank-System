# Blood Bank Management System 🩸

A C++ console-based application that simulates a fundamental Blood Bank Management System. This project demonstrates the practical application of Object-Oriented Programming (OOP) principles and robust data structures.

## 🚀 Features

* **Donation System:** Allows users to donate blood by entering their name, blood type, and amount.
* **Withdrawal System:** Enables users to request blood units, checking the bank's real-time inventory.
* **Inventory Management:** Automatically updates the available quantities of each blood type using C++ `std::map`.
* **Strict Input Validation:** Ensures continuous system stability by preventing invalid inputs (e.g., rejecting negative amounts or undefined blood types).
* **Continuous Event Loop:** The system runs continuously via a main menu until the user explicitly chooses to exit.

## 🛠️ Technologies Used

* **Language:** C++
* **Concepts:** Object-Oriented Programming (OOP), Data Structures (`std::map`), Control Flows, Input/Output Stream Management.

## 💡 How to Run

1. Clone the repository or download the `Blood_bank.cpp` file.
2. Compile the code using any standard C++ compiler (e.g., `g++ Blood_bank.cpp -o bloodbank`).
3. Run the executable (`./bloodbank` on Linux/Mac or `bloodbank.exe` on Windows).
